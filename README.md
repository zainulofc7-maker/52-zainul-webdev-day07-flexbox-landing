## Flexbox Concepts Demonstrated

- **Horizontal Navbar:** `display: flex`, `justify-content: space-between`, and `align-items: center` distribute branding and navigation links.
- **Hero Section:** Responsive flex layout aligning header typography, copy, and action buttons.
- **Wrapping Product Cards:** Product grid utilizing `display: flex`, `flex-wrap: wrap`, `flex-grow`, and `flex-basis: 260px` to fluidly reflow cards across screen widths.
- **Pricing & Centered Login Form:** Centering and vertical/horizontal alignment using `justify-content: center` and `align-items: center`.
- **Responsive Navigation:** Mobile-friendly drawer menu with smooth toggle interaction.
